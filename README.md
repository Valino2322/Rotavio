# 🛍️ Rotavio Marketplace

Маркетплейс БУ товаров для Telegram

## 📱 О проекте

Rotavio - это полноценный маркетплейс внутри Telegram, где можно покупать и продавать товары.

## 🚀 Функционал

- 🛍️ Каталог товаров
- 🔍 Поиск
- ⭐ Избранное
- 🛒 Корзина
- 👤 Профиль
- 💰 Баланс
- 📱 Mini App

## 🔧 Установка

1. Клонируйте репозиторий
2. Откройте index.html в браузере
3. Или используйте GitHub Pages
